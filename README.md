# Neon Trade Journal

Installable web app for journaling NQ, ES and GC scalps: video clips, calendar, P&L stats, day notes, three neon themes and a daily ForexFactory market brief.

- Open the GitHub Pages link on your phone, then Share → Add to Home Screen.
- Trades, notes and clips are stored on the phone (IndexedDB). Use Settings → Export backup regularly.
- `news.json` is refreshed every weekday morning by a scheduled Claude task.
